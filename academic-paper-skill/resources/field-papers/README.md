# field-papers/

Put Markdown conversions of papers from your research field here (for example your reference repository), converted with `scripts/convert_to_markdown.py`. `scripts/build_section_phrases.py` turns them into a list of the openers and phrases each section uses, and `scripts/search_resources.py` searches them. Files in this folder are ignored by git and stay on your computer.

Papers from a specific target journal belong in that journal's profile folder instead: `resources/journals/<journal>/papers/`.
