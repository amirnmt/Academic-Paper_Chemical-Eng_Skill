# Phrase bank for engineering research articles

Generic sentence stems organized by function. Adapt them to the content; never use a stem whose strength does not match the evidence. X, Y, Z stand for your content; [n] for citations.

Stems are starting points: follow each with a specific fact, number or citation. Avoid decorative stems such as "plays a crucial role" or "highlights the importance of" (see `avoid-ai-signs.md`).

For a much larger collection, see the Academic Phrasebank of the University of Manchester (https://www.phrasebank.manchester.ac.uk/).

## Introduction

**Establishing importance**
- X is widely used in …
- X controls / determines / limits … (state how)
- X accounts for [value] % of … / X is the main source of …
- Growing demand for X has increased interest in …
- Accurate prediction of X is essential for the design and operation of …

**Background and definitions**
- X is defined as …
- In this paper, the term X refers to …
- X is commonly described by …

**Previous research**
- X has been studied extensively [n].
- Previous studies have shown that …
- Several approaches have been proposed to …
- X et al. [n] developed / proposed / reported / demonstrated …
- Early work on X focused on …; more recent studies have …
- Considerable progress has been made in …

**Problem and gap**
- However, … remains unclear.
- However, these models assume …, which does not hold when …
- Few studies have addressed …
- To date, no study has examined …
- Little is known about … under …
- Previous work has been limited to …
- These approaches do not account for …
- The reported effects of X on Y are contradictory [n, n].
- A model that … is still lacking.

**Aim and contribution**
- This study aims to …
- The objective of this work is to …
- To address this gap, we …
- This paper presents / proposes / develops …
- The main contributions of this work are: (i) …; (ii) …; (iii) …
- Unlike previous studies, the present model …
- The remainder of this paper is organized as follows: Section 2 …

## Literature review

**Summarizing**
- Three main approaches can be distinguished: …
- Most studies of X have used …
- A common assumption in these models is …

**Synthesizing and comparing**
- Similar trends were reported by [n–n].
- In contrast to [n], [n] found that …
- These studies differ mainly in …
- While [n] focused on …, [n] considered …
- Taken together, these studies indicate that …
- Reported values range from … to … depending on …

**Evaluating**
- This approach captures … but neglects …
- A limitation of these models is …
- The validity of this assumption has not been tested for …
- These results are restricted to …

## Methods

- X was supplied by … (company, city, country).
- The experiments were carried out in …
- X was measured using …, with an accuracy of …
- Following the procedure of [n], …
- The method of [n] was modified to …
- To ensure / avoid / minimize …, …
- Each experiment was repeated [n] times.
- The model is based on the following assumptions: …
- The equations were discretized using … and solved with …
- Grid independence was verified by …
- The model was validated against …
- Model accuracy was quantified by the root-mean-square error, defined as …
- The data were divided chronologically into training, validation and test sets.
- Hyperparameters were selected by …

## Results

**Pointing to figures and tables**
- Figure X shows / compares / presents …
- As shown in Figure X, …
- Table X summarizes …
- It can be seen from Figure X that …

**Reporting trends and values**
- X increased from A to B as Y increased.
- X decreased by [value] % when …
- X reached a maximum of [value] at …
- X remained nearly constant over …
- No significant effect of X on Y was observed.
- The largest deviation occurred at …

**Agreement and error**
- The predictions agree with the measurements within [value] %.
- The model reproduces the trend but overpredicts X by …
- The lowest error was obtained with … (RMSE = …).
- Most of the points lie within the ±10 % band.

**Transition**
- Having established …, we now examine …
- The next section considers …

## Discussion

**Restating findings**
- The results show that …
- The main finding of this study is that …
- This study has shown that …

**Explaining**
- This can be explained by …
- A possible explanation is that …
- This behaviour is likely due to …
- This difference may be attributed to …
- One reason for this may be …

**Comparing with literature**
- This is consistent with [n], who reported …
- These results confirm the findings of [n] for …
- In contrast to [n], we found …
- The discrepancy with [n] probably arises from …

**Unexpected results**
- Contrary to expectations, …
- This result was not anticipated, because …
- An unexpected finding was …

**Implications**
- These results suggest that …
- These findings have important implications for …
- In practice, this means that …
- This approach could be used to …

**Caution**
- These results should be interpreted with caution because …
- Under the conditions studied, …
- Within the investigated range, …
- It is possible that …
- The data do not allow a firm conclusion about …

**Limitations and future work**
- One limitation of this study is …
- The present model does not account for …
- This assumption may not hold for …
- Further work is needed to establish whether …
- Future studies should investigate …
- An extension of the model to … is under way.

## Conclusion

- This study has shown that …
- The results demonstrate that …
- The main conclusions are as follows: …
- These findings provide a basis for …
- The proposed approach enables …

## General functions

**Defining:** X is a … that … / X can be defined as … / In this context, X refers to …

**Classifying and listing:** X can be divided into … / There are three types of … / The following factors were considered: …

**Comparing and contrasting:** X is higher than Y / Compared with X, Y … / Whereas X …, Y … / Similarly, … / Conversely, …

**Describing quantities:** a large proportion of …; the majority of …; approximately half; a small fraction; an order of magnitude higher than …

**Describing trends:** a steady increase; a sharp decrease; a gradual decline; levelled off at; fluctuated between; peaked at; reached a plateau.

**Cause and effect:** X leads to Y / Y results from X / X contributes to Y / X is associated with Y / As a consequence of X, …

**Giving examples:** for example, … / such as … / X is a typical example of … / This is illustrated by …

**Being critical:** X fails to account for … / The main weakness of X is … / X does not explain … / X relies on the questionable assumption that …
