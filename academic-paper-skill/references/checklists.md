# Checklists

Use the section checklist after drafting each section and the final checklist before submission. Each section reference file has a fuller checklist at its end.

## Evidence base
- [ ] Every repository paper has a note with numbers, conditions and relevance.
- [ ] Theme map and comparison matrix built; gap visible in the matrix.
- [ ] `refs.bib` keys stable and matching the notes.

## Introduction
- [ ] Funnel from broad to narrow.
- [ ] Gap specific, cited and justified.
- [ ] Objective states property, system and means.
- [ ] Contributions specific; method choice justified.

## Literature review
- [ ] Organized by themes; synthesized, compared, evaluated.
- [ ] Closest studies in a comparison table.
- [ ] Disagreeing results included; ends at the gap.

## Methods
- [ ] Reproducible: conditions, parameters with units and sources, software versions.
- [ ] Assumptions next to equations; boundary/initial conditions complete.
- [ ] Numerical accuracy and validation described; data-driven details complete.
- [ ] Every later result has a method here.

## Results
- [ ] Same order and subheadings as Methods.
- [ ] Main finding first, then numbers.
- [ ] No duplication across text, tables and figures.
- [ ] Measurement and interpretation separated.

## Figures and tables
- [ ] Axes with quantity and unit; readable at print size.
- [ ] Consistent style; uncertainty shown.
- [ ] Captions self-explanatory; numbered in order of citation.

## Discussion and Conclusion
- [ ] Findings interpreted, compared with named studies, mechanisms explained.
- [ ] Contribution and closure of the gap stated.
- [ ] Limitations bounded; future work specific.
- [ ] Claims at the right strength; no new results; no throwaway ending.
- [ ] Conclusion answers the objective with key numbers.

## Abstract, title, keywords
- [ ] Abstract self-contained, results-centred, within limit.
- [ ] Title specific and searchable; keywords not repeating title words.

## Final check before submission
- [ ] Objective worded identically in title, abstract, Introduction, Discussion and Conclusion.
- [ ] Each method has a result and each result a method.
- [ ] Numbers identical wherever they appear (abstract, text, tables, figures, conclusion).
- [ ] All symbols defined, units SI, significant figures consistent, abbreviations defined once.
- [ ] Every citation verified (DOI resolved); in-text citations and reference list match; no duplicates; no open `[CHECK]` items.
- [ ] Journal guidelines met: template, length, reference style, figure format, declarations.
- [ ] Eight Cs checked: compliance, completeness, composition, correctness, clarity, conciseness, consistency, courtesy.
- [ ] Likely reviewer objections answered in the text: novelty, validation, uncertainty, limitations, overclaiming.
- [ ] `scripts/check_ai_signs.py` run on every section; each flag rewritten with a specific fact, number or citation, or deleted; no placeholders left.
- [ ] Plain words where they are precise (is, has, used); academic words where they add precision; no decorative intensifiers.
- [ ] AI assistance disclosed as the journal requires.
- [ ] Read aloud once from beginning to end.
